# 渲染与交互优化（2026-11-23）

## 目标与实现

- **预览/导出分离**：Topo、Blocks 和 Marble 在实时预览采用最大边 760 / 1120 / 1680px 三档，默认 Auto 根据设备判断。PNG、SVG 按原设定分辨率独立生成，不从缩小的预览截图导出。自定义尺寸限制为 256–3840px，像素总量上限约 1475 万。
- **Blocks Worker**：几何层先显示；纹理、颗粒和半调滤镜迁移到独立 Worker。快速参数修改后延迟 70ms 执行，旧任务主动终止并用版本号过滤结果。在安全沙盒、浏览器限制或 Worker 失败时自动回退到主线程。
- **输入校验**：URL 参数、本地存储与外部加载的设置使用同一白名单校验，非有限数值、非法枚举、颜色格式等全部丢弃或限制范围。
- **效果可重复**：Topo/Blocks 颗粒使用固定种子的伪随机数；同一设定重复生成的图像噪声不再因 Math.random() 变化。
- **Marble**：独立 WebGL2 高清图片导出；上下文丢失与恢复、录制超时及离开页面时资源清理；开始录制前检查 H.264 编码器支持。
- **画布工具栏**：缩放、适合窗口、Auto/快/平衡/精细预览、撤销/重做；导出与录制状态反馈。
- **其他**：保存前检查预览是否尚在处理，改善键盘编辑、颜色输入和已保存作品的触屏操作。

## 边界和后续工作

- 仍有部分 p5.js 的几何生成与初次噪声图生成留在主线程。完整导出会占用主线程，预览模式可减轻日常操作但无法完全消除高负载时卡顿。
- 嵌入 UI-Vault 的沙盒若不允许跨域 Worker，Blocks 将自动回退主线程。
- Marble 动画的高清 PNG 是基于当前设置单独渲染的静态帧，**不是**从运行中动画的同一时间点精确采样。
- MP4 使用 WebCodecs/H.264 + mp4-muxer（已有弃用提示），录制最长 60 秒。后续可以评估流式复用器及更完整的录制进度/失败处理。
- 浏览器端交互性能与视觉回归仍需在不同真实设备上测试；构建成功不等于绘制性能达标。
- 依赖安全性应通过 npm audit 具体报告复核生产依赖，避免对所有依赖直接执行破坏性版本升级。

## 手工回归清单

1. 从主页进入三种工具，切换后新页面立即出现，预览自动更新，切换速度和结果正确。
2. Topo 与 Blocks 连续拖动滑块、快速切换工具、在加载中离开或返回，不应出现旧图片覆盖新图片。
3. 分别导出 2048 和 3840px 的 PNG/SVG，检查文件尺寸、像素质量、图形效果。
4. 在精细预览和自定义画布下操作，测试横竖比例与缩放按钮。
5. 保存、恢复、撤销重做、调色、导航快捷键、键盘编辑与触屏打开收藏。
6. 录制 Marble 视频、停止后下载、超过 60 秒自动结束、离开页面后不再继续编码。
7. 模拟 WebGL 上下文丢失、Worker 创建失败、无 VideoEncoder、恶意链接配置与资源不足环境。
